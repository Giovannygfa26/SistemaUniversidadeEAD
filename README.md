## Objetivo do software

O Sistema Universidade EAD tem como objetivo auxiliar no gerenciamento
das informações acadêmicas de uma instituição de ensino a distância.

O software permite centralizar o cadastro e o gerenciamento de cursos,
turmas, professores, matrículas e materiais, facilitando a organização
das informações e o acesso aos dados da instituição.

## Funcionalidades do sistema

- Autenticação de usuários por login e senha;
- Controle de acesso de acordo com o tipo de usuário;
- Cadastro de cursos;
- Cadastro de turmas;
- Cadastro de professores;
- Cadastro de matrículas;
- Cadastro de materiais;
- Consulta dos registros cadastrados;
- Exclusão de registros;
- Exibição de indicadores no painel principal;
- Integração com banco de dados MySQL.
